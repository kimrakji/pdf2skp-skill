# 초기 PDF 파이프라인 PoC 결과 — 2026-10-08

아래는 초기 파이프라인 구현 시점의 기록이다. 이후 독립 C API exporter로 실제 `.skp` 생성·재열기와 기존 Ruby 결과 비교를 수행했다. 현재 native 저장 검증은 [C SDK PoC 결과](c-sdk-poc.md)를 기준으로 본다.

`Skill + 고정 스크립트`의 초기 패키지를 만들고 PDF 추출부터 벽체 모델 입력까지 로컬에서 검증했다. 실제 `.skp`는 아직 생성하지 않았다. ChatGPT Pro 설치·실행과 회사 디자이너 간 일관성 평가는 수행하지 않았다.

## 실제 입력 PDF

| 도면 | 직선 채움 면 후보 | 원본 렌더·좌표 추출 | 벽체 의미 판별 |
| --- | ---: | --- | --- |
| 마석로51 2층 | 846 | 성공 | 긴 세로 벽체 한 구간만 선택 |
| 서리재 | 1,859 | 성공, 페이지 회전 270도 반영 | 미평가 |
| 방통대 출판 문화원 | 892 | 성공 | 미평가 |

후보 개수는 벽체 개수가 아니다. 가구·기호·해치가 포함된다. 직선 복합 면은 PDF의 채움 규칙으로 병합하고 내부 구멍을 보존했다. 곡선·유효하지 않은 경로·면적 없는 경로는 제외 수량을 남겼다. 원본 PDF의 `/PageMode` 중복 정의 경고가 있었으나 이번 추출과 렌더는 완료됐다.

## 실제 도면의 부분 시험

마석 도면의 왼쪽 아래 긴 세로 벽체 한 구간을 원본 이미지에서 확인해 선택했다. 같은 PDF 채움 경로에 있던 두 삼각형을 하나의 직사각형으로 추출했다. 상단 `14,850` 및 하단 `12,550` 치수의 연장선 교점으로 축척을 교차 확인했다.

- 선택 후보: `p1-f00001-001`
- 축척: 약 37.8325 mm/pt
- 모델 윤곽: 약 99.9 × 8,848.2 mm
- 시험 높이: 2,700 mm
- 변환 범위: `partial`, 이 벽체 한 구간
- native 저장 상태: `not_executed`

이 선택은 이번 PoC에서 원본을 직접 대조하며 작성했다. 전체 도면을 공통 Skill로 자동 판별하거나 여러 디자이너가 반복 실행한 결과가 아니다.

## 고정 스크립트 검증

Python 3.12.14에서 17개 자동 검증이 통과했다. 삼각형 병합, 높이 변경 시 XY 유지, 낮은 벽체 높이 유지, 반복 geometry hash 일치, 치수 기준 충돌 거절, 원본 및 추출 hash 불일치 거절, 잘못된 후보 ID 거절, 영역 밖 벽체 거절, confidence·미해결 항목의 검토 필요 처리, 다른 높이의 면적 겹침 거절, 비정상 수치 거절, JSON 계약 검증, 회전 PDF 처리, even-odd/non-zero 채움과 구멍 보존을 확인했다.

`quick_validate.py`의 Skill 형식 검사와 `ruby -c`의 문법 검사도 통과했다. Ruby 문법 검사로 SketchUp API 실행 성공이 확인되는 것은 아니다.
