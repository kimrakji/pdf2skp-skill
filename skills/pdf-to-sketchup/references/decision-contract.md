# 밑그림 선택 계약

AI는 평면도 영역·축척·후보 선택을 JSON으로 기록한다. 사용자가 JSON을 작성하거나 벽종류를 확정하는 흐름은 없다. 기본 `compile`은 밑그림이며 `--strict`만 기존 검증 모드다.

| 필드 | 의미 |
| --- | --- |
| `source_sha256`, `page` | 추출 결과의 원본 hash와 페이지 |
| `evidence_sha256` | `summary.json`의 hash. 추출기가 바뀌면 다시 선택 |
| `scope` | `partial`: 일부만 선택, `full_page`: 평면도 전체를 보고 선택한 밑그림. 전체 복원 정확성 보증과 다름 |
| `crop_bbox_pt` | 표시 페이지의 왼쪽 위 원점, `[left, top, right, bottom]`, pt |
| `calibration` | 실제 치수선 기준점 0~2쌍. 두 쌍이 있으면 교차 확인 |
| `scale_hint` | 치수를 읽지 못할 때 `{mm_per_pt, evidence}`. 인쇄 1:N이면 `N * 25.4 / 72` mm/pt |
| `walls` | 원본 후보 ID, `default`/`low`, 판단 근거, confidence. 빈 배열도 허용 |
| `unresolved` | 출력 차단 대신 밑그림 보고서에 남길 한계 |

축척은 첫 실제 치수 기준을 사용한다. 두 기준 차이가 2%를 넘으면 밑그림은 첫 기준을 사용하고 경고를 남긴다. 실제 치수 한 쌍도 허용한다. 치수가 없으면 `scale_hint`, 그것도 없으면 회사 기본 인쇄 축척 1:100을 사용한다. 연장선 교점을 측정하며 화살표 끝은 기준점으로 사용하지 않는다.

`--outlines` 추출은 직선 채움 면(`f`), 실제 닫힌 stroke 경로(`o`), 수평/수직 평행 선의 겹침(`pair`)을 제공한다. 평행 선 후보는 0.5~12pt 간격, 최소 18pt 길이, 두께의 6배 이상인 겹침 구간이다. 문틈을 연결하거나 선 끝을 임의로 연장하지 않는다. 후보에는 가구와 기호가 있으므로 원본 렌더를 함께 보고 선택한다. CAD 레이어 이름은 참고이며 후보별 레이어 판정은 없다.

선에서 복원한 후보와 낮은 confidence의 후보는 `Walls_Suggested`/`Walls_Low_Suggested`로 분리한다. 같은 높이·같은 종류의 연결된 단면을 병합하고 0.1mm 격자에 맞춘다. 확정 벽과 추정 벽이 겹치면 확정 벽을 우선하고, 높이가 겹치면 기본 높이를 우선하며 보고서에 기록한다. 낮은 벽의 차감 후 형상은 낮은 그룹에 남는다.

원본 참조 이미지는 crop과 같은 XY 축척으로 `Source_Plan` 그룹에 들어가며 Z=-1mm다. 벽체가 없어도 참조가 포함된 `.skp`를 출력한다. 곡선·스캔·개구부 상세를 과도하게 복원하지 않고 참조에서 수동 편집할 수 있게 남긴다.

`--strict`는 두 개의 서로 다른 치수, 선택 벽체, 미해결 사항 없는 결과를 요구한다. 밑그림에서는 의미상 불확실성만 허용하며 원본/추출 hash, 후보 존재, 유효한 면, 높이·좌표·부피 검증을 해제하지 않는다. 이미지 hash와 참조 위치·크기·포함 이미지 데이터도 native 저장·재열기에서 확인한다.
